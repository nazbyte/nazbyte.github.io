How it works

Almost every online compressor gives you a quality slider and hopes for the best. That is useless when a form says under 100 KB. This tool works backwards from the number you type: it keeps compressing until the file fits, then stops — so the highest quality that still meets the limit is the one you get.

  • For JPG and WebPIt searches encoder quality, keeping the largest dimensions possible, and only reduces the size of the image if quality alone cannot reach the target.
  • For PNGPNG has no quality setting, so the tool reduces the colour palette to an indexed palette and shrinks the dimensions only as far as it has to. Transparency is kept.
  • Already small enough?The image is passed through untouched. Re-encoding a file that already fits would only lose quality for nothing.

Nothing is uploaded. That is the point.

Most compressors send your file to their server, process it, and send it back. That is why they need size limits, daily quotas, and an account. This tool does the work in your browser using the canvas and PNG encoders that are already part of it.

Your image never leaves your device. There is nothing to sign up for, nothing stored, and no quota — and it keeps working if your connection drops.

Questions

Can I compress an image to an exact size like 100 KB?

Yes. Type the target size in KB and the tool will not stop until the output is at or below it. For JPG and WebP it does this by finding the highest quality that still fits. For PNG it reduces the colour palette and, if needed, the dimensions.

Why is there no signup or limit?

Because everything happens inside your browser. There is no server doing the work, so there is no cost per file and no reason to ration it.

Can I compress several images at once?

Yes — drop in as many as you like and all of them are compressed to the same target size. There is no file-count limit.

Which format should I choose?

JPG or WebP for photographs, PNG for logos, signatures and screenshots with flat colours. WebP usually produces the smallest file for the same visible quality, and every modern browser supports it.

Does it work on my phone?

Yes. The tool runs in any modern browser on Android and iPhone, and nothing is uploaded so it works even on a slow connection.
